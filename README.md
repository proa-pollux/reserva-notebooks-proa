# Reserva Notebooks PROA

Al iniciar pedirá el usuario y contraseña del profesor (usuario: nombre_apellido, contrasena: DNI), una vez ingrese se vera un apartado que dice reservar y otro que dice ver reservas.

### Reservar: 
Al ingresar se le pedirá el día, la cantidad de notebooks que necesita, el curso, y de que horario a que horario las va usar, el docente una vez que confirme la reserva tendrá siempre la oportunidad de marcar como devuelta, una vez que se cumpla el horario tendrá un margen de 15 minutos para hacerlo, sino se marcara como devuelta automáticamente, si lo hace manual tendrá la opción de escribir observaciones.

### Ver reservas:
Al ingresar hay que elegir las reservas de que día se quiere ver(máximo 1 mes), al entrar se vera una vista simple (curso, horario y devueltas o no), si presionan en alguna de ellas, se verán mas especificaciones además de las nombradas anteriormente (profesor, notebooks, cargadores y zapatillas utilizadas).
